innerHTML - Getting and Setting HTML Content

What is innerHTML?

innerHTML allows you to get or set the HTML content inside an element. It parses and renders any HTML tags you assign to it.

Basic innerHTML Usage

Simple Text Replacement

Click the button to replace the content below with HTML:

Original content
const elem = document.getElementById('demo1'); elem.innerHTML = '<p>This is <em>new</em> content!</p>';

Building Complex HTML

Dynamically Build a List

Click to build a list...

elem.innerHTML = ` <h3>Shopping List</h3> <ul> <li>Milk</li> <li>Bread</li> <li>Eggs</li> </ul> `;

Appending Content with innerHTML

Add Content Without Replacing

Line 1

// Append by reading current innerHTML and adding to it elem.innerHTML += '<p>New line</p>';

Reading innerHTML

Get HTML Content

HTML Content with nested tags
const html = elem.innerHTML; console.log(html);

innerHTML with Form Elements

Dynamically Create Forms

Click to create a form...

elem.innerHTML = ` <form> <label>Name: <input type="text"></label> <label>Email: <input type="email"></label> </form> `;

!!! innerHTML Security Considerations !!!

Security Risk: XSS (Cross-Site Scripting)

innerHTML can be dangerous if you insert unsanitized user input. It will execute scripts and can be used for attacks.

See the next file (04-innerhtml-injection.html) for a demonstration of innerHTML security risks!

innerHTML vs other methods

Method Pros Cons
innerHTML Quick, familiar, supports HTML Parses HTML, loses event listeners, security risk
textContent Safe, fast, sets plain text Can't add HTML elements
appendChild Precise, preserves listeners, safe More verbose
