🛠️ DOM Manipulation - Create, Insert, Remove, Clone

What you'll learn:
  • createElement: Create new DOM elements
  • appendChild: Add elements as children
  • insertBefore: Insert elements at specific positions
  • removeChild: Remove elements from DOM
  • remove: Remove element itself
  • cloneNode: Duplicate elements

1. Creating Elements with createElement

Create new elements and add them to the page:

const div = document.createElement('div'); div.textContent = 'New element'; div.className = 'element-box'; parent.appendChild(div);

Demo:

2. appendChild - Adding Elements to Parent

Add elements to the end of a parent element:

const parent = document.getElementById('parent'); const newChild = document.createElement('div'); parent.appendChild(newChild); // Adds as last child

Demo:

3. insertBefore - Insert at Specific Position

Insert an element before a specific child:

const parent = document.getElementById('parent'); const newElement = document.createElement('div'); const targetChild = parent.children[0]; parent.insertBefore(newElement, targetChild); // Inserts before first child

Demo:

4. removeChild - Remove Child Element

Remove a specific child element from its parent:

const parent = document.getElementById('parent'); const childToRemove = parent.children[0]; parent.removeChild(childToRemove); // Removes the child

Demo:

5. remove() - Remove Element Itself

An element can remove itself directly (without needing parent):

const element = document.getElementById('myElement'); element.remove(); // Removes itself from DOM

Demo:

Click on items to remove them individually

6. cloneNode - Duplicate Elements

Create an exact copy of an element and its children:

const original = document.getElementById('element'); const clone = original.cloneNode(true); // true = deep clone (includes children) parent.appendChild(clone);

8. Replacing Elements

Replace one element with another using appendChild (moves element):

const parent = document.getElementById('parent'); const newChild = document.createElement('div'); const oldChild = parent.children[0]; parent.replaceChild(newChild, oldChild); // Replaces oldChild with newChild

9. Performance Considerations

Adding many elements one by one can be slow. Better approach:

// ❌ SLOW - causes many reflows for (let i = 0; i < 1000; i++) { const div = document.createElement('div'); container.appendChild(div); // Each appendChild causes reflow } // ✓ FAST - single reflow const fragment = document.createDocumentFragment(); for (let i = 0; i < 1000; i++) { const div = document.createElement('div'); fragment.appendChild(div); } container.appendChild(fragment); // Single reflow

Method Purpose Example
