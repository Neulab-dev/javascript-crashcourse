DOM Selectors - Querying Elements

Different ways to select elements:
  • getElementById: Select by ID (returns 1 element)
  • getElementsByClassName: Select by class name (returns HTMLCollection)
  • getElementsByTagName: Select by tag name (returns HTMLCollection)
  • querySelector: Select with CSS selector (returns 1st match)
  • querySelectorAll: Select with CSS selector (returns all matches)

getElementById - By ID

Select a single element by its unique ID:

const element = document.getElementById('element1'); // Returns the element with id="element1" // Returns null if not found

getElementsByClassName - By Class Name

Select all elements with a specific class (returns HTMLCollection - live):

const elements = document.getElementsByClassName('sample-element'); // Returns HTMLCollection of all elements with class="sample-element" // HTMLCollection is "live" - updates if DOM changes

getElementsByTagName - By Tag Name

Select all elements with a specific tag name (returns HTMLCollection - live):

const divs = document.getElementsByTagName('div'); // Returns HTMLCollection of all <div> elements // Also live

querySelector - CSS Selector (First Match)

Select first element matching a CSS selector:

const element = document.querySelector('.sample-element'); // Returns first element matching the CSS selector // Returns null if no match // Works with: document.querySelector('#id') // by ID document.querySelector('.class') // by class document.querySelector('div') // by tag document.querySelector('[data-x]') // by attribute document.querySelector('div.class') // combined document.querySelector('div > p') // child selector

querySelectorAll - CSS Selector (All Matches)

Select all elements matching a CSS selector (returns NodeList - static):

const elements = document.querySelectorAll('.sample-element'); // Returns NodeList of all matching elements // NodeList is "static" - doesn't update with DOM changes

!!! DUPLICATE IDs - A Common Problem

⚠️ WARNING: IDs must be unique in HTML! But it's a common mistake...

Here are examples of duplicate IDs on this page:

These elements have duplicate IDs (BAD PRACTICE):

Duplicate Element 1 - id="duplicate-id"
Duplicate Element 2 - id="duplicate-id"
Duplicate Element 3 - id="duplicate-id"
What happens with duplicate IDs?
  • getElementById() returns only the FIRST matching element
  • querySelector() also returns only the FIRST
  • querySelectorAll() cannot easily target duplicates by ID alone
  • CSS styling applied to the ID affects ALL duplicates

Complex Selectors - Combining Techniques

CSS selectors allow complex queries:

  • element > child - Direct children only
  • element descendant - All descendants
  • element + adjacent - Next sibling
  • element ~ general - Any following sibling
  • element:nth-child(n) - Specific child position
  • element:first-of-type - First of that type
  • element.class1.class2 - Multiple classes
  • element[attr="value"] - Attribute value
  • element[attr^="prefix"] - Attribute starts with
  • element[attr$="suffix"] - Attribute ends with
  • element[attr*="contains"] - Attribute contains
  • :not(.class) - Negation

Method Comparison

Method Returns Live? CSS Selectors? Best For
getElementById 1 Element or null N/A ✗ No Single unique ID
getElementsByClassName HTMLCollection ✓ Yes ✗ No By class name
getElementsByTagName HTMLCollection ✓ Yes ✗ No By tag name
querySelector 1 Element or null N/A ✓ Yes First match with CSS
querySelectorAll NodeList ✗ No ✓ Yes All matches with CSS

When to Use What

Use getElementById when:

  • You need a single unique element
  • You know the ID exists
  • Simple, fast lookups

Use querySelector/querySelectorAll when:

  • You need complex selectors
  • You want to combine multiple criteria
  • You prefer CSS-like queries (most modern approach)

Avoid getElementsBy* methods:

  • They return live collections (can be unpredictable)
  • Limited selector capability
  • querySelector alternatives are more flexible
