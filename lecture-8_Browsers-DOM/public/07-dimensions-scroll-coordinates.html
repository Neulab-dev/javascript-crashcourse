DOM Dimensions, Scroll & Element Coordinates

Learn about:
  • Element dimensions: offsetWidth, offsetHeight, clientWidth, clientHeight, scrollWidth, scrollHeight
  • Element position: offsetLeft, offsetTop, getBoundingClientRect()
  • Scroll position: scrollX, scrollY, scrollLeft, scrollTop
  • Window dimensions: innerWidth, innerHeight, outerWidth, outerHeight

1. Element Dimensions

Different ways to measure element size:

const elem = document.getElementById('element'); // Including border & padding elem.offsetWidth // Width (border + padding + content) elem.offsetHeight // Height (border + padding + content) // Excluding border & padding elem.clientWidth // Width (padding + content only) elem.clientHeight // Height (padding + content only) // Full size with overflow (scrollable area) elem.scrollWidth // Full width if scrollable elem.scrollHeight // Full height if scrollable

2. Window & Viewport Dimensions

Measure browser window and viewport:

// Window outer size (includes browser UI) window.outerWidth // Full browser window width window.outerHeight // Full browser window height // Viewport (visible area) window.innerWidth // Viewport width window.innerHeight // Viewport height // Screen size (monitor) window.screen.width // Physical screen width window.screen.height // Physical screen height window.screen.availWidth // Available width (excludes taskbar) window.screen.availHeight// Available height (excludes taskbar)

3. Scroll Position

Track scroll position of page and scrollable elements:

// Page scroll position window.scrollX // or window.pageXOffset - horizontal scroll window.scrollY // or window.pageYOffset - vertical scroll // Element scroll position elem.scrollLeft // Horizontal scroll of element elem.scrollTop // Vertical scroll of element

4. Element Position - offsetLeft & offsetTop

Get element position relative to its offset parent:

const elem = document.getElementById('element'); elem.offsetLeft // Distance from left edge of offset parent elem.offsetTop // Distance from top edge of offset parent elem.offsetParent // Reference element (usually closest positioned ancestor) elem.parentElement// Direct parent element

5. getBoundingClientRect() - Absolute Position

Get element's position relative to viewport (useful for animations, positioning):

const rect = elem.getBoundingClientRect(); rect.top // Distance from top of viewport rect.bottom // Distance from bottom of viewport rect.left // Distance from left of viewport rect.right // Distance from right of viewport rect.width // Element width rect.height // Element height rect.x // Same as left rect.y // Same as top

Common Use Cases

When to use each property:

  • offsetWidth/offsetHeight: Get visible element size with borders
  • clientWidth/clientHeight: Get content size excluding borders
  • scrollWidth/scrollHeight: Check if element is scrollable
  • offsetLeft/offsetTop: Position relative to positioned parent
  • getBoundingClientRect(): Position for viewport-relative operations (animations, overlays)
  • scrollX/scrollY: Track page scroll for parallax, sticky headers
  • window.innerWidth/innerHeight: Responsive design calculations
